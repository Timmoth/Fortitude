# Code of Conduct

## In short

Be decent to people. This is a small open source project; nobody is here to have a bad time.

## What that means

- Assume good faith. Most disagreements are misunderstandings.
- Critique code and ideas, not people.
- Accept that maintainers have limited time, and that "no" to a feature is not a judgement
  of the person asking.
- No harassment, personal attacks, or unwelcome attention of any kind.

## Scope

This applies to issues, pull requests, discussions, and anywhere else the project is being
worked on.

## Enforcement

Report a problem privately to the maintainer via
[GitHub](https://github.com/Timmoth). Reports are handled in confidence. Maintainers may edit
or remove contributions, and may block anyone whose behaviour is persistently a problem.
